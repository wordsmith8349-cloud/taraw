# Contributing to TARAW

Thanks for considering a contribution! This is a small learning-friendly
open-source project. Keep changes focused and explain why they help.

1. Open an issue to discuss major changes before writing a large patch.
2. Fork the repository and create a branch for your change.
3. Add or update tests for changes to scanning behavior.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Submit a pull request with a clear description of the change.

Please do not submit private credentials, API tokens, or personal information.
Be respectful and constructive when reviewing or discussing contributions.
